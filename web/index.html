COMO LER ESTE PAINEL

Dados para análise, com contexto.

A chuva histórica vem dos boletins pluviométricos da CGE. Para cada dia, o painel calcula a média das estações disponíveis na região; os totais mensais e anuais somam essas médias diárias. Temperatura, umidade e pressão vêm do BME280 conectado ao ESP32.

Avaliação de enchentes: os dados atuais ainda não incluem medição de chuva em tempo real nem registros de ocorrências de alagamento para validar uma previsão. Por isso, este painel apresenta medições e padrões históricos sem classificar risco imediato.
